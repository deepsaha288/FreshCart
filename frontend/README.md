# Backend & Frontend
## FreshCart - Grocery Ordering Platform

A full-stack application for ordering fresh groceries online with OTP-based authentication.

## Getting Started

See [START_HERE.md](START_HERE.md) for quick setup instructions.

## Features

### Phase 1 - Authentication
- ✅ Phone-based OTP login
- ✅ JWT token management
- ✅ Secure password hashing
- ✅ Refresh token mechanism

### Phase 2 - Products & Cart
- ✅ Product catalog with pagination
- ✅ Shopping cart with price snapshots
- ✅ Category filtering
- ✅ Full-text search

## Tech Stack

### Backend
- FastAPI
- MongoDB with Beanie ODM
- JWT Authentication
- Bcrypt hashing

### Frontend
- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Zustand state management
